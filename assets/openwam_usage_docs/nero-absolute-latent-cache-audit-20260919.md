# 本地绝对 EEF：VAE 预编码 + 已有 T5 缓存对照（2026-09-19）

> 后续进展：该报告记录隔离验证时的状态。用户随后授权继续，正式可选缓存已接入，并在 0/1/5/6 卡 tmux 中启动全量编码流水线，见 [完整缓存实现与执行说明](nero-absolute-video-cache.md)。

本次仅完成隔离原型和数值/性能验证，未接入正式训练器、未构建全量缓存、未启动正式训练。
正式 YAML、reader、归一化统计和模型实现的哈希均未变化。这里是**冻结编码器输出缓存**，没有启用 `torch.compile`。

## 配置和范围

- GPU 0、3、4、7；每卡 B64、梯度累积 1、global batch 256；同一个官方 foundation 初始化。
- 保持 5 epochs 对应的 16045 步完整 LR 日程；仅诊断退出上限为 24 步，关闭 W&B 和权重保存。
- 在线、缓存各完成四卡 24 步；比较步骤 5–24 的每步最慢 rank 墙钟。
- 同样的 6144 个窗口、顺序、种子、LR、动作/proprio/mask、绝对 EEF 归一化和三相机映射。
- VAE 输入始终是 64×3×9×384×320，输出 64×48×3×24×20；按完整窗口编码，bf16 原样保存。
- T5 沿用已批准的 run-local cache；每 rank 首次编码一次，缓存 3 条完整任务文本，随后不再运行 T5。
  所有短测步骤的 T5 context 与在线基线逐元素一致。冻结权重仍保留，保存格式没有变更。
- 原型临时保存标签便于对照，实际正式接入时仍应通过原 reader 读取动作、状态及其 mask。

## 数值与训练语义

缓存读写本身逐位无损，冻结 VAE 返回均值 latent，不做 posterior 随机采样。
没有随机颜色增强；不缓存扩散噪声、timestep、优化器或梯度。
TI2V 首帧条件仍来自相同窗口 latent 的第 0 帧；mask、动作、proprio、文本与原路径相同。

但**离线重新编码不与当前在线稳定阶段逐位一致**：

- 96 个 B64 编码批次中 4 批完全一致，即 4 个 rank 各自的第一步。
- 其余在线训练阶段曾在显存压力下切换到慢卷积内核；离线 VAE-only 没有同等显存压力。
  这与先前实际 kernel trace 的内核回退诊断一致，但本次没有逐个重新抓取 kernel trace。
- 所有窗口的首帧 latent 完全一致；未来 latent 有 bf16 数值差异。
- 全批次最坏相对 L2：0.4100%；最大绝对差 0.09375。
- 只改变 VAE 计算所处的内存环境，数学定义、归一化、尺度和相机/时间映射没有变化。

固定 fresh base、同一随机噪声、每任务一个真实窗口（3 窗口），诊断启用确定性反向：

- 原路径重复控制：0 个梯度张量不同，相对 L2 0。
- 离线与在线 latent 对照：1651/1651 个梯度张量不同，
  梯度相对 L2 7.963429%，最大绝对差 0.0026855469。
- Loss 相对变化（百分数）：`{"loss": 0.03727429846614475, "loss_video": 0.0399633772739042, "loss_action": -0.5295490586880828}`。
- 这个小批量梯度审计不改变正式 B64 配方，也不是完整 B64 梯度一致性证明。

## 全量成本与最小正式接入方案

本次 6144 窗口预编码墙钟 97.51 s（不包含加载模型前的启动时间）；
平均 VAE B64 编码 2.501 s。按本次随机窗口吞吐外推：

- 全量 821344 窗口，bf16 latent 本体 105.74 GiB，另有索引/manifest 开销。
- 四卡预编码约 3.62 h；不是全量实测保证。
- 加本配方训练纯计算约 39.77 h；
  还需加初始化、保存和共享服务器波动。缓存可在后续相同像素/编码器实验中复用。

正式接入应保持 opt-in：独立 cache 目录和配置项，不按 GPU 数量改变策略。
按 `(episode, 原始窗口起点)` 映射完整 9 帧 latent，不能先编码整段 episode 再切片，
因为 Wan VAE 的因果卷积在每次 encode 开始清空历史状态。
采用分片及原子完成 manifest；绑定数据/视频指纹、相机布局、预处理代码、VAE 权重 SHA256、
精度与窗口形状，拒绝缺失、过期或未完成缓存。bf16 不转换成 fp16，也不量化压缩。
原 reader 继续产生绝对动作、proprio 和 masks；仅跳过视频解码/在线 VAE。
Wan TI2V 预处理增加明确的 latent 输入入口，首帧条件由这些 latent 构造。
原在线 reader 和模型保存/部署路径保留。T5 已有缓存无需重复改造。
